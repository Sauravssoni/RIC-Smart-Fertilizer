# Evaluator Start Here — RAJ-URVARA AI

RAJ-URVARA AI is Syntheon Tech Private Limited's submission to Rajasthan's **AI/ML-Driven Smart Fertilizer Formulation & Distribution Framework** challenge.

## 3-minute evaluation path

1. **Read the problem thesis in the repository README.** RAJ-URVARA does not replace iFMS/DBT, Soil Health Card, AgriStack or Department systems; it adds prediction, agronomic lineage, constrained allocation, custody assurance and offline execution around them.
2. **Open the evaluator console.** Start in Command Centre, then inspect FarmGraph, Formulation, DemandCast, Supply Network, Trace & Quality and SUTRA Edge.
3. **Run the jury mission.** Stress → FarmGraph evidence → P10/P50/P90 forecast → fairness-constrained FlowOpt → officer Decision Receipt → TraceGraph custody → SUTRA offline acknowledgement → impact contract.
4. **Inspect the implementation evidence.** `services/`, `tests/test_release_gates.py`, `contracts/integration_status.json`.
5. **Read the scale contract.** `docs/PILOT_90_DAY.md` and `docs/VISION_2030.md`.

## What the prototype proves now

- governed deterministic nutrient-rule path and SLM policy boundaries;
- probabilistic fertilizer-demand logic with stock-out censoring and hierarchy checks;
- fairness-constrained stock transfer primitives;
- tamper-evident trace-chain primitives;
- human-review-only Leakage/Quality Sentinel semantics;
- SUTRA duplicate-safe offline synchronization;
- working evaluator-facing operational flows using synthetic district-level signals and clearly cited public aggregates.

## What is deliberately not claimed

- production access to Rajasthan or Government of India credentials/APIs;
- live farmer PII or Aadhaar data;
- already-achieved pilot KPI targets;
- autonomous fertilizer prescription, subsidy denial, enforcement or official-record mutation;
- statewide production certification.

**Pilot ask:** ₹79.50 lakh for a 90-day evidence-producing controlled pilot. Statewide rollout is intentionally scoped after measured pilot evidence.
