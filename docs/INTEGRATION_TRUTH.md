# Integration Truth Standard

- **LIVE_PUBLIC**: published non-sensitive Government evidence embedded as-is.
- **CONTRACT_READY**: adapter/schema is designed; production credentials/authorization are required.
- **DEMO_SANDBOX**: synthetic/local operating signal for evaluator interaction.

No Government connector is represented as live unless it actually is. Farmer PII, Aadhaar values and raw sensitive evidence are not included in this repository.
