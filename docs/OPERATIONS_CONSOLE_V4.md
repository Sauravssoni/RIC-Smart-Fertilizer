# Evaluator Release v4 — State Fertilizer Operations Console

The v4 evaluator interface is deliberately an **operations console**, not a pitch microsite.

## What is executable

- State command centre with district stock-cover / P90 demand risk map
- Live operations feed and district action queue
- Persistent human decision workbench with Decision Receipts
- DemandCast P10/P50/P90 scenario recomputation
- Warehouse physical/digital reconciliation and GPS exception simulation
- Farmer/Plot demo lookup with SHC freshness and Nutrient Passport
- TraceGraph mutation/tamper detection
- Quality and Leakage Sentinel human-review prioritization
- SUTRA-ID Edge assisted offline workflow with idempotent sync
- Automated judge demo: stress → forecast → fair allocation → human authorization → trace custody → SUTRA receipt → duplicate-safe sync

All operational district/warehouse/farmer values are `DEMO_SANDBOX`. Public Kharif 2026 state-level fertilizer aggregates remain `LIVE_PUBLIC`. Production Government adapters remain `CONTRACT_READY` unless explicitly authorized.
