# RAJ-URVARA AI — 90-Day Pilot Mission

The pilot is designed to answer one procurement-grade question: **does RAJ-URVARA measurably improve fertilizer planning, traceability and field execution enough to justify scale?**

## Phase 0 — Days 0–15: contracts, baseline, safety

- Department workshops and pilot-area selection.
- Integration/data dictionary for iFMS/DBT, Soil Health Card, crop/sowing, weather and approved State systems.
- Security/privacy review and integration truth registry.
- Baseline forecast and stock-cover metrics agreed with the Department.
- Synthetic sandbox retained until official credentials/approvals are issued.

**Exit gate:** signed interface/data contracts, baseline metrics, security controls and pilot scorecard.

## Phase 1 — Days 16–35: shadow intelligence

- FarmGraph evidence model and source/version lineage.
- DemandCast district × grade × week probabilistic forecasts.
- NutrientTwin / UrvaraRX governed formulation path.
- No operational stock movement generated by the system.

**Exit gate:** reproducible forecasts, model card, calibration report, deterministic agronomy tests and officer review.

## Phase 2 — Days 36–65: controlled operations

- FlowOpt fairness-constrained transfer recommendations.
- StockPulse warehouse/dealer reconciliation.
- TraceGraph lot/custody events with QR/mobile-GPS first.
- Leakage/Quality Sentinel human-review queues.
- SUTRA-ID Edge assisted offline workflow where field conditions justify it.

**Exit gate:** every consequential recommendation has a Decision Receipt and human authorization.

## Phase 3 — Days 66–90: UAT, impact proof, handover

- Department UAT and field training.
- Security/performance/offline tests.
- Comparison against agreed planning baseline.
- Deployment/runbook, API contracts, model rollback, source registry and handover package.
- State scale/no-scale recommendation based on measured evidence.

## Proposed acceptance gates

These are **pilot targets, not claimed achieved results**:

| Gate | Proposed threshold |
|---|---:|
| Forecast error | ≥10% relative WAPE improvement vs Department-agreed baseline |
| P90 calibration | 85–95% empirical coverage |
| Selected stock-cover warning | ≥24h lead where data availability permits |
| Required custody events | ≥95% completeness |
| SUTRA duplicate business events | 0 |
| Consequential recommendations | 100% Decision Receipt coverage |
| SLM unsupported numeric dosing | 0 in safety test set |

## Pilot archetypes

Use three contrasting operating contexts rather than one convenient district: a high-intensity fertilizer-demand area, a remote/low-connectivity area, and a logistics-sensitive route/warehouse cluster. Final pilot districts are to be selected jointly with the Department based on data readiness and operational relevance.
